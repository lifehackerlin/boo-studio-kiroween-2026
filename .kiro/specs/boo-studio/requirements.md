# Boo Studio requirements
Created November 16, 2026 for a new Kiroween project. No ClaritySnap code is reused.

1. A creator can choose a supplied original illustration or upload a local image.
2. The creator can choose a palette, frame, message and decorative stamps, with immediate preview.
3. Uploaded images remain in the browser; the app has no upload service, analytics or remote processing.
4. The creator can export a 1200x1200 PNG, including a transparent-background option.
5. The creator can save and restore a draft locally and reset to defaults.
6. Controls must work with keyboard input and fit mobile screens.
7. Invalid image files must produce a readable error and leave the prior image intact.
8. Export must render the same layout shown in the preview.

These specifications were prepared by Codex. Their presence is not evidence of Kiro usage. Record actual Kiro contributions separately.
